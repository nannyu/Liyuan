# Liyuan Agent 1.4.0

本次更新主题：正本清源

## 1. 提示词与引擎各归其位（本次核心）

彻底将预设、提示词、harness 三个长期混淆、争抢模型扮演教导权的职能拆开，各归其位。模型不再被两套互相矛盾的指令搅乱。

## 2. 写作流程改为 skill 驱动

摒弃旧版死板又啰嗦的「卡片」（回看卡 / 修复卡 / 续写卡）式结构。换成 **skill**——一套按场面、按需灵活调用的写作方法库，取代卡片式的机械注入。

## 3. 预设回到提示词

预设的内容不再被拆成零散的「技能」让模型按需猜着读，而是完整回到提示词层，不再污染引擎。效果反而更稳定。

## 4. skill 体系重构

skill 分常驻、必读、按需三种送达形态——常驻每拍在场，必读每轮强制读取，按需由模型按场面自取。内置可视化编辑器，可新建、编辑、删除 skill 并指定送达方式。

## 5. 补上「世界状态更新」轮次

上一版收尾漏了「更新世界状态」一步，本版补上：每拍结束后模型核对并记录本拍的世界变化（时间、地点、关系、物品），记忆更连贯。

## 6. 预设 AI 分拣

导入预设时自动分析，标出无用、有害内容，删掉绝大多数用不上的东西（仍需人工二次筛选删减）。
