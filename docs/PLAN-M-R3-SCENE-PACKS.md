# PLAN-M-R3：场面包 + 中段锚点

2026-08-11 立。承 PLAN-RECTIFY M-R3（默认写作库）与 8/11 实弹解剖（星光学院拍，dump `_askbeat.txt`）：四段正文零落笔前思考、零 `skill_read`、文笔=裸基线。诊断定案：

- **中段无锚点**：开拍有规划卡、收笔有判定注入，中段只有「已续写」回执与纯事实进度行——skill「每轮三件事」与「场面包指路」是没有触发器的死文（skill 调用率基线 17.6%，且几乎全靠 nsfw 场面撞脸）。
- **思考文笔一题两半**（用户 8/11 定案）：决策半（入口/承接/节奏）是选择题，思考通道有效，缺的是时机锚点；质感半（句子好不好）不是决策，**想不出来只能仿出来**——投放是生成时刻上下文里的示范段，不是思考指令（v1.3.0「全力构思文笔」咏叹调实弹无效已死）。
- 两件是一对：只做锚点=指向空库；只做场面包=回到没人指路的 17.6%。

## 1. 中段送达：剧情指导强制调用（8/11 四改定形）

演进（四次用户定向）：①锚点不指全局写作 skill →②常驻剧情指导→③指路式证伪→全文每轮注入→④**全文注入也证伪**（faux 抓包证实【剧情指导】全文逐字在每个写作轮上下文里，模型中段思考仍 12-17 字、零引用；「强制思考从未失败」经 8/10 解剖复核实为不成立——v1.3.0 回看卡时代逐段思考同样坍缩 13-27 字）→用户定案「**那就强制调用**：注入里明明确确写着调用剧情指导 skill 进行创作」。

终态（思考指令模型不执行，工具调用模型可靠执行——把任务从思考通道搬到动作通道）：

- 剧情指导回归**标准拉取 skill**（进 L1 索引与 skill_read 名单）。
- 进度行指令句：`每段落笔前先 \`skill_read\`「剧情指导」构思本段，再 \`draft_append\`。可读场面包：{包名投影}。`
- **append 受理门**（结构保证，抢跑 seal 拦截同款）：模型没读剧情指导就交段→本段首次不受理，回执「先 skill_read「剧情指导」构思这一段，再重交」；读了（工具回执送全文）再交放行；**每段重新计门、每段只拦一次**（执意重交放行，防空转——安全阀思路同封笔催告）。harness 内部代收 draft_write 不拦。
- 成本：每段 +1~2 次工具往返，用户知情点名。

## 2. 场面包（skills/<名>/SKILL.md，agentskills.io 布局，非常驻）

首批六包（拉取档）：**情欲**（历史命中最高：14/18）、**打斗**、**对峙**、**静场**（本次实弹的仪式/交接场面即属此类，写烂的现行样本）、风格包**去八股**（对着实弹缺陷写：解释性明喻/道具式感官/节奏平线/功能性对白/冗余修饰，附病例改写对）+ **ask判断**（用户 8/11 增设：剧情轮次的 ask 触发靠剧情指导指路顺便救——判据=戏内递话 vs 戏外岔路判别式 + 三条升格条件 + 禁区 + 反模式「用戏内问句糊过岔路」）。

每包结构（<200 行）：
1. frontmatter `name` + `description`——description 只写 when（何时读），场面措辞（「触发写成场面会发火」实弹判据）；
2. **何时用/何时不用**表；
3. **核心写法**——少量硬条款，决策形状（选什么、砍什么），不是美德口号；
4. **示范段**——一段绝佳示范文（载荷核心，模仿>遵守）；
5. **反模式表**——对着实弹缺陷写：解释性明喻（「像在清点货物」）、道具式感官（一件一句点到就走）、节奏平线、功能性对白。

署名：梨园自带库，正经自写（不从预设进口——命令堆无示范=素材不合格）。
