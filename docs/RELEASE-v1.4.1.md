# Liyuan Agent 1.4.1

## 更新

### 项目完整备份、导出与导入

角色卡、世界书、预设、persona、技能、会话、记忆等全部数据可整体打包下载，也可从备份包完整恢复，恢复前自动留快照。Docker 部署一并补全数据持久化，重建容器不丢数据。

### 正文输出

正文所见即所得——流式输出与最终正文完全一致：被判定拒收的段落不再提前上屏，正文尾段不再重复、状态栏不再丢失。

### 全流程文字留档

逐拍记录正文、思考、工具调用、注入与合并的完整时序，可完整回溯模型的流式过程与思考，据此校准预设。

## 修复

### 模型配置被覆盖

修复手动设置的兼容字段（supportsDeveloperRole 等）在保存、启用、生成快照时被丢弃的问题。DeepSeek 等模型正确降级，不再误用 developer 角色导致连接失败。

### 世界书条目无法开启

修复世界书导入后默认关闭的条目无法开启的问题。启用时同步写回源文件，导入即关闭的条目可正常开启。

### Docker 部署自带 skill 不显示

修复 Docker 部署时三个自带 skill 不显示的问题。skills 目录挂卷后首启未回填默认 skill，现从镜像内置副本补回。

## 安装包

| 平台 | 文件 |
|------|------|
| Windows | `Liyuan-1.4.1-windows.zip` |
| Linux | `Liyuan-1.4.1-linux.zip` |
| macOS | `Liyuan-1.4.1-macos.zip` |
| 校验 | `SHA256SUMS.txt` |
| **Docker** | 仓库 `docker-compose.yml`，`docker compose up -d --build` |

> 装了旧版的用户，主页会出现「新版本 v1.4.1」提示，点开即可一键升级。

## 快速开始

见各包内 `RELEASE.txt` / `start.bat` · `start.sh` · `start.command`。需要 Node.js **≥ 22**。

## 提醒

梨园目前没有官方适配的预设，导入的预设需自行调整。预设对模型输出的影响很大，可结合本次新增的全流程留档查看模型思考，让 AI 辅助删减冗余内容。

本版即源于一处预设问题：某预设要求「正文标题必须输出 `### 正文`，正文使用 `<content></content>` 包裹」，模型照做后把已写好的正文又重复输出了一遍，并把末尾的状态栏挤丢。
