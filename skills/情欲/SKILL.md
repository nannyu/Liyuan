# 情欲场面

## 何时用 / 何时不用

| 用 | 不用 |
|---|---|
| 亲吻、爱抚、交合、口交、调教、事后余韵 | 只是提及性关系存在的叙述句 |
| 挑逗与拉扯——衣服还没脱、张力已经在的段落 | 用一句话带过的暗场（「一夜过去」） |
| 当众羞耻、权力关系下的身体展示 | 医疗/检查等非欲望语境的身体描写 |

## 核心写法

1. **欲望有主语**。每一段先定这一段是谁在「要」——主动方的要和承受方的要不一样，交替给。只写动作不写要，就是体操解说。
2. **一次只放大一个感官**。这一段是温度，下一段是声音，再下一段是重量。五感一起上=全都没有。
3. **心理与身体错拍**。身体到了嘴上不肯认、嘴上认了身体在抖——错拍是情欲的戏眼，同步了就只剩生理流程。
4. **慢进快出**。前戏与拉扯占大头，越靠近高潮句子越短；余韵再放慢。全程一个速度=没有速度。
5. **对白要失控**。情动中的人说不出完整句——断句、重复、答非所问。语法完好的调情对白是排练过的。

## 示范段

> 他的拇指停在她后颈第一节脊骨上，没有往下。
>
> 就这么停着。她数到第四次呼吸的时候，终于明白他在等什么——等她自己把背弓起来，把那截脊骨送到他手心里。灯太亮了，她想，亮得连耳根的温度都藏不住。
>
> 「说想要。」
>
> 「……我、」她听见自己的声音散了，捡不起来，「你明知道。」
>
> 拇指往下滑了一节。只一节。她的膝盖先于她认了输。

**为什么好**：拇指「停着」比任何动作都重（写等待不写动作）；「数到第四次呼吸」把张力量化成体感；「明知道」是嘴硬、膝盖是投降——错拍；全段只放大了「一节脊骨」一个点。

## 反模式

| 反模式 | 病征 | 改法 |
|---|---|---|
| 生理流程账 | 动作A→动作B→动作C，谁做都一样 | 每段先答「这段谁在要、要什么」 |
| 感官大杂烩 | 一段里香味+喘息+触感+灯光全到场 | 砍到只剩一个，放大它 |
| 解释性明喻 | 「像小猫一样呻吟」「像火一样烫」 | 删喻体，直接写体感本身 |
| 完好的对白 | 情动中说出语法完整的长句 | 打碎：断句、吞掉的半句、重复 |
| 全程匀速 | 从脱衣到高潮句长不变 | 高潮前句子砍到十字以内 |
