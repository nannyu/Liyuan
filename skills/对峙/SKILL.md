# 对峙场面

## 何时用 / 何时不用

| 用 | 不用 |
|---|---|
| 谈判、审问、摊牌、威胁、试探底细 | 已经动手（读「打斗」） |
| 权力不对等的问话（主对仆、官对民） | 日常闲聊、没有利害的对话 |

## 核心写法

1. **每句话都有目的，目的都不在字面上**。开口前先想这个人这句话想换到什么——问天气的可能在探你昨夜在哪。字面与目的重合的对白是念台词。
2. **沉默是武器**。谁先开口谁先让步；一段好的对峙里至少有一处「谁都不说话」，写清这段沉默压着谁。
3. **小动作泄底**。嘴上的话滴水不漏，手上的茶盏、指节、目光落点在出卖真话——张力全在言行的缝隙里。
4. **强势方少说**。权力在手的人用短句、用停顿、用「嗯」；解释得多的那个是弱势方——话量本身就是权力关系的写照。
5. **交锋要换手**。至少一次攻守易位——一句话让原本压人的一方顿住。全程单方碾压是训话不是对峙。

## 示范段

> 「茶凉了。」他说。
>
> 没人应。侍女进来换茶，又出去，门合上的声音很轻。她看着新茶冒出来的白气，没碰。
>
> 「王大人昨夜去了西市。」她说，「我没问是谁陪着。」
>
> 白气散了半截，他才笑了一声：「你想换什么？」
>
> 「不换。」她把茶推回去，「我只是想让大人知道，我可以不问。」

**为什么好**：「茶凉了」目的不在茶（在催她开口）；她不接=不让步；亮底牌只亮一半（「没问是谁」）；「你想换什么」是攻守易位的顿；「我可以不问」把威胁说成恭顺——字面与目的全程分离。

## 反模式

| 反模式 | 病征 | 改法 |
|---|---|---|
| 念台词 | 双方把意图明说：「你是想威胁我吗」「没错」 | 意图沉到字面之下，靠错位显出来 |
| 机关枪对白 | 你一句我一句无间隙到底 | 插入沉默、动作、目光的段落 |
| 弱势方口才爆发 | 被审的人对答如流气势不落 | 话量与权力挂钩，弱势方话多而碎 |
| 情绪直播 | 「他愤怒地」「她心虚地」打头 | 删副词，用小动作与话缝泄露 |
| 无换手 | 一方全程压制到收尾 | 至少给一句让强势方顿住的话 |
