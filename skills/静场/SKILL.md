# 静场场面

## 何时用 / 何时不用

| 用 | 不用 |
|---|---|
| 仪式、典礼、交接（流程在走、心在别处） | 有正面冲突推进的段落 |
| 独处、守夜、赶路、告别、事后余韵 | 用一句话带过的时间跳转 |

## 核心写法

1. **静场的戏在内外落差**。外面越平静、越程序化，里面越要有东西在动——仪式照章进行，视角人物数着章程走神到别处。外静内也静＝没有戏，是流水账。
2. **选一件物承载情绪**。不直接写「她难过」，把难过放进一件具体的东西——落地的旧饰链、凉掉的茶、门缝里最后一线灯。整段只用这一件，反复回到它。
3. **时间可以变形**。静场里一秒可以写三行（等待、凝视），一个时辰可以一句带过（「香燃到第三节」）——匀速推进是记录不是叙事。
4. **声音写小不写大**。静不是没有声音，是只剩下小声音：衣料摩擦、更漏、自己的心跳。写出一两个小声音，静才立得住。
5. **结尾要有一丝不对**。完全圆满的静场没有后劲；收在一个轻微的错位上——该走的人回了一次头，该平静的手抖了一下。

## 示范段

> 按印用的是左胸。流程单上这么写的，她也就这么做了。
>
> 印泥比想象中凉。工作人员托着文件的手很稳，一式三份，她按了三次，每一次都端端正正——学院教过，印痕缺角要重按，重按算污损，污损扣评级。她已经不会缺角了。
>
> 第三份按完，指腹上留着一小片红。她垂着手站在那里，没有去擦。台侧的旧饰链被收进一只黑绒袋里，袋口抽紧，像一截结束了的绳子。
>
> 评级已经不重要了，她想。可是手指还是按得那么端正。

**为什么好**：外面是流程（三份文件），里面是「评级已经不重要了、身体还在服从」的落差；情绪全在物上（印泥的凉、指腹的红、抽紧的绒袋）；小声音与小动作（没有去擦）；结尾「还是按得那么端正」是那一丝不对。

## 反模式

| 反模式 | 病征 | 改法 |
|---|---|---|
| 流程记录 | 步骤A→步骤B→步骤C，视角人物只是摄像机 | 给内在一条与流程错开的线 |
| 情绪点名 | 「她感到悲伤」「心中五味杂陈」 | 把情绪装进一件物，写物不写名 |
| 道具清单 | 一段里灯光、饰链、目光各点一句就走 | 砍到一件，反复回到它 |
| 匀速流水 | 每件事均分篇幅 | 该停的地方停三行，该跳的一句跳过 |
| 圆满收束 | 一切妥当、心绪归平 | 收在一个轻微错位上 |
